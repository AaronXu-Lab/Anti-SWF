# 飞天忍者猫：原版逻辑沿用审计

审计对象是 H5 `BUILD_VERSION = 20260801-2`。原版基线为：

- `Flying-Ninja-Cat.swf`：`928d0195fcc107cb6c845ef6fef7472fff4a878611844450956a5b55a783e04e`
- `FSAGOGUN_RES.swf`：`b2ef09ad088d47fde2e08e7a1f5dc06adf393ed0d861f9735ce53b52a693885a`

结论：地图、硬币、计分、基础运动常量和主要素材已有明确原版依据。
`20260801-1` 又恢复了抓绳角度/释放/帧内顺序、MovieClip 碰币语义、角色子动画和
死亡缓动。帮助页、最高分持久化和部分声音/UI 仍是 H5 近似或新增逻辑，
因此仍不能把当前版本整体描述为“完全沿用原版逻辑”。

## 判定口径

- **精确移植**：能在 AS2、时间轴动作、按钮动作、SWF 标签/矩阵或隐藏碰撞元件中
  找到直接依据，且数值、顺序和边界语义一致。
- **等价适配**：实现机制因浏览器平台而变，但不应改变可观察的游戏规则。
- **有意差异**：因独立运行、浏览器限制或用户明确要求而改变，并已公开记录。
- **近似/自造**：没有原版依据，或虽然方向相似，但公式、时序、范围、帧数或状态
  转移不同。

## 等价或平台适配

| H5 实现 | 原版机制 | 评价 |
| --- | --- | --- |
| `requestAnimationFrame` + 30 FPS 固定步长累加器 | Flash `onEnterFrame` | 合理适配；250ms 追帧上限是浏览器新增保护 |
| Canvas 图层绘制 | MovieClip 深度和时间轴 | 必要适配；绘制锚点仍需逐项验证 |
| Pointer Events、触摸、响应式缩放 | 鼠标与空格键、固定舞台 | 新增可用性，不属于原版规则 |
| 首次触屏申请全屏、去除 tap/焦点高亮 | Flash 固定舞台，无移动浏览器外壳 | 用户要求的移动端适配；受浏览器安全策略限制，系统全屏必须在首次用户手势中请求 |
| 限制为 4 个并发图片请求 | Flash 资源加载 | 只影响载入稳定性，不应影响玩法 |
| HTMLAudio 和拒绝自动播放兜底 | `JhSound` | 必要适配；音量和停止语义仍需校正 |
| `Map` 记录每组金币 | `CoinItem.parr` 的 9 槽循环数组 | 正常流程基本等价，但不是原算法，遗漏组会长期保留 |
| xorshift 随机数 | Flash `random()` | 概率分布接近、序列不一致；只可称测试友好适配，不是精确移植 |

## 仍是近似或自行生成的逻辑

### 流程、反馈或记录语义

| 区域 | 当前 H5 与原版的差异 |
| --- | --- |
| 最高分 | H5 使用 `localStorage`，每次加分立刻更新最高分；原版主要使用 `scope.bestscore`/服务器值，并在无旧记录时不会在本局中持续刷新石掌数字。离线持久化可以保留，但必须标成产品适配，显示和 Best 特效触发仍应单独对齐 |
| 帮助页 | H5 把六个关键画面放进自制弹窗，用上一页/下一页/关闭控制；原版是 268 帧演示时间轴，含六段停点、自动继续、鼠标演示、跑步/旋转声音和原按钮动作 |
| 结算入口 | 原版结算有 replay、help 和隐藏 rank 逻辑；H5 目前只保留 replay。移除提交/排名是用户要求，但 help 入口也一并消失，并非同一项要求 |
| 声音 | H5 自定音乐/音效音量；落地时额外播放 `snd_jumpdown`，原 `SetGame` 没有此触发；标题页当前不会像原版一样启动标题音乐；原版按钮 rollover 的 `snd_ropecatch` 未沿用；H5 也没有等价 `allStop()` 停掉所有瞬时克隆音效 |
| 标题交互 | 点击热区、Space/Enter 开始、hover 发光和上移 2px 是 H5 逻辑；原版使用 Flash Button 状态和 rollover/release 动作 |
| 时间暂停 | 石猫表情的 5 秒在原版由真实时间 `setInterval` 控制；H5 按 150 个模拟 tick 计时。隐藏标签页或掉帧时语义不同 |

### 视觉、工程实现或低概率边界差异

- 分数、最高分、结算分数使用 Canvas 字体重画，未沿用 `AddNum` 数字 MovieClip。
- 结束图上的“最终得分”是 H5 新增；原版 ending 时间轴没有这层 Canvas 文本。
- 标题底部文字、帮助面板、加载页、按钮阴影和部分绳索描边/阴影是 H5 绘制。
- 绳索原版为 1px、颜色 `0x96BAB4`；H5 使用 2px、`#96BDC4` 并加发光。
- 角色残影使用旧位置再次画当前 PNG 并设 0.08/0.15 alpha；原版用两张 200×200
  `BitmapData` 快照，alpha 50/20。位置思想相同，像素结果不等价。
- 原版每生成一个新块就 `shift()` 最旧块，始终保留 6 块；H5 按 x 过滤，通常保留
  7 块。隐藏在屏外时大多不影响玩法，但不是原算法。
- 原版道具容器在 x<-150 时整组删除；H5 按单个硬币中心 x<-70 删除，生命周期不同。
- 原版代码中的 `GameMode.mode == "2x"` 加速分支、测试地图/道具编辑器、演示模式、
  计数/排行/提交接口没有移植。
  远程接口不应恢复到独立 H5；其余项目必须明确标成省略，而不是“已还原”。

## 有意差异

- 独立 H5 不调用原版远程计数、提交和排行接口。
- 按用户要求，结算面板移除了中文“游戏结束”上方装饰以及提交/排名按钮。
- 浏览器音频需要用户交互后才能可靠播放。
- 触摸、响应式缩放、无障碍状态文本和 `window.__ninjaGame` 调试接口是 H5 增强。
