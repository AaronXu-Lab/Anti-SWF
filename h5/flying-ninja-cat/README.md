# 飞天忍者猫 · HTML5 重制版

这是从 `swfs/flying-ninja-cat/Flying-Ninja-Cat.swf` 反编译逻辑后重写的
纯 Canvas 版本。
运行时不加载 SWF、不使用 Ruffle,也不访问外部接口。

## 运行

在仓库根目录:

```bash
python3 -m http.server 4173
```

打开:

```text
http://127.0.0.1:4173/h5/flying-ninja-cat/
```

不需要安装 npm 依赖。

## 操作

- 鼠标、触摸或空格:起跳;
- 空中再次按下:发射绳索;
- 抓住后按住:向上摆动;
- 松开:向下摆动;
- 最高分保存在当前浏览器的 `localStorage`。

## 已还原

- 640×480、30 FPS 固定步长;
- 跑、跳、射绳、抓绳、摆荡、旋转、坠落和重新开始;
- 原版地图块宽度、速度、重力和分数公式;
- `MapData.as` 中的全部地图结构;
- 金币坐标编码、普通/高分金币、整组奖励和难度加速;
- 原版标题、游戏背景、35 帧角色、地图块、金币、Ready/Go、
  Game Over、帮助页和音频;
- 鼠标、触摸、键盘和响应式缩放。

## 与 SWF 的差异

- 原版的远程提交/排行接口没有移植;
- `ItemData.as` 有数百组逐格金币表。当前版本保留相同的 4×N 坐标编码和
  关卡弧线规则,但没有逐条照搬所有随机金币图案;
- 浏览器禁止未交互自动播放,所以标题音乐会在首次点击后才开始;
- 原 SWF 和 Ruffle 仅用于本地视觉回归,H5 包本身不依赖它们。

调试时可在控制台执行:

```javascript
window.__ninjaGame.snapshot()
```

它会返回当前状态、分数、速度、地图块、金币数和角色状态。
